## 🏆 Featured Projects

### [📊 Operational Stability Analysis](https://github.com/Cardasz/operational-stability-analysis)
This project applies descriptive statistics techniques to analyze the operational time stability of a machine fleet. Designed to address a business problem in operations—determining whether productive capacity is predictable (stable) or erratic (risky)—the pipeline processes frequency distributions to extract measures of central tendency and dispersion.

By calculating the mean, sample variance, and standard deviation, the system derives the Coefficient of Variation (CV), translating raw data into a three-level, actionable risk classification. Originally developed as an academic model, the project was completely restructured following software engineering best practices, with clear separation of responsibilities across data handling, calculations, business rules, and graphical visualization using histograms, along with automated test coverage.

**Technologies:** `Python 3.11+`, `pandas`, `numpy`, `matplotlib`, and `pytest`.

### [🐍 Python ELT Pipeline — Power BI Integration](https://github.com/Cardasz/powerbi_etl)
This project presents an automated ELT pipeline developed in Python to optimize data workflows within a corporate Business Intelligence environment. The solution combines web automation, data processing, and API integration to reduce manual steps in the process of updating information consumed by Power BI.

The application architecture was designed with a strong focus on security and traceability. The end-to-end workflow replaces manual routines by combining web-based data extraction, HTTP requests, and spreadsheet processing. Credentials are securely isolated throughout the environment, while native system resources are used to generate detailed logs for every stage of the data pipeline.

**Technologies:** `Python 3.11+`, `pandas`, `numpy`, `selenium`, `webdriver-manager`, `requests`, `openpyxl` and `python-dotenv`
